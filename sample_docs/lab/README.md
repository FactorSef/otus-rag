# Мастерская «Ржавый гусь» — внутренняя база знаний

«Ржавый гусь» (англ. *Rusty Goose Print Lab*) — небольшая мастерская 3D-печати на заказ. Здесь собраны внутренние документы мастерской: регламенты, журнал инцидентов, описание парка принтеров, профили филаментов, служебные утилиты и логи печати.

> Все люди, адреса, принтеры и события в этой папке вымышлены. Документы созданы для демонстрационной базы знаний RAG.

## Кратко о мастерской

- Основана **3 февраля 2019 года** Глебом Сорокиным.
- Находится в бывшей котельной по адресу **г. Томск, ул. Рябиновая, 12**. Принтерная — помещение **Б-14** на первом этаже, склад филамента — помещение **Б-16** (сухая комната).
- Талисман мастерской — живой гусь по имени **Шуруп**, который живёт во дворе котельной. Именно в честь его ржавого цвета мастерская и получила название.
- Выдача заказов: **по средам и субботам с 11:00 до 19:30**.

## Парк принтеров

Шесть принтеров, у каждого своё имя (птицы, деревья и ягоды). Подробности — в [`fleet.yaml`](./fleet.yaml).

| Имя | Модель | Прошивка | Для чего используется |
|---|---|---|---|
| «Сойка» | Anet A8 (глубоко переделанный) | Marlin | PLA, учебные и тестовые печати |
| «Кедр» | Voron 2.4 350 | Klipper | ABS/ASA в закрытой камере |
| «Пустельга» | Bambu Lab P1P + AMS | штатная | многоцветный PLA/PETG |
| «Жёлудь» | Creality Ender-3 S1 | Klipper | только TPU |
| «Клюква» | Snapmaker U1 | штатная (Klipper) | многоцветные детали, PLA + поддержки PVA |
| «Мамонт» | Tronxy X5S | Marlin | крупные детали до 330 мм, только PETG |
