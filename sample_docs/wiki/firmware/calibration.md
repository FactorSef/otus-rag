# Калибровка принтера
3D-принтеры — отличная вещь, но их нужно калибровать, чтобы они печатали в правильных размерах, выдавливали нужное количество филамента и обеспечивали точный и стабильный нагрев хотэнда и стола. В этом руководстве описан процесс калибровки принтера.

Руководство рассчитано в первую очередь на прошивку Marlin/SkyNet, но настройки можно сохранить в EEPROM, и процесс будет практически одинаковым для любого принтера. В частности, руководство ориентировано на принтеры с декартовой кинематикой.

## Калибровка экструдера
#### Что понадобится
- Отрезок филамента длиной 150 мм (лучше белый или светлый, чтобы метки были хорошо видны)
- Штангенциркуль
- Маркер

#### Шаги
- Снимите хотэнд, чтобы не тратить впустую много филамента

- Отмерьте и отметьте 120 мм на отрезке филамента
![](/images/reprap/firmware/img_1264.jpg)

- Вставьте филамент в экструдер так, чтобы верх метки был чуть выше корпуса экструдера
![](/images/reprap/firmware/img_1265.jpg)

- Выдавите 100 мм филамента

```
G91  ;relative positioning
G1 E100 F300 ;extrude 100mm at half max speed
G90 ;absolute positioning

```

- Измерьте расстояние между второй меткой и корпусом экструдера.
![](/images/reprap/firmware/img_1268.jpg)

Расстояние окажется больше, меньше или равно 120 мм. Если оно равно 120 мм — всё готово, мотор экструдера откалиброван правильно. В нашем примере расстояние на 17,91 мм *меньше* 120. Значит, пройдено 120 − 17,91 = 102,09 мм. Близко, но не совсем точно.

Чтобы вычислить новое значение E-steps на мм, нужно знать текущее. Для примера примем исходное значение 90 шагов/мм.

Расчёт такой:

''Steps<sub>new</sub> = (Distance<sub>expected</sub> / Distance<sub>actual</sub> ) * Steps<sub>Original</sub>''

Подставляем значения в формулу и получаем новое число шагов на мм:

''Steps<sub>new</sub> = ( 100 / 102.09 ) * 90''

''Steps<sub>new</sub> = 88.16 steps/mm''

Сохраните новое значение в принтер командой ''M92 E88.16''

**ПРИМЕЧАНИЕ**: эта настройка не сохранится после перезагрузки! Её нужно записать либо в EEPROM (через меню принтера), либо в ''configuration.h''. Сохранять её таким способом нужно для того, чтобы повторить калибровку и убедиться, что значение точное.

Чтобы сохранить настройку в ''configuration.h'', отредактируйте строку:

```c
#define DEFAULT_AXIS_STEPS_PER_UNIT   {100,  100, 400, 88.16} // { X, Y, Z, E }

```
