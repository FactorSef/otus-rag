# 3DPrint.Wiki

**Знания о принтерах, на которых мы печатаем.** Справочник по 3D-печати, который ведёт сообщество: руководства по конкретным принтерам, заметки о прошивках, модификации и всё то, что хотелось бы знать раньше.

## Основные страницы

- [Bambu Lab P1P](/printers/bambu-lab/p1p) — руководства, апгрейды, моды, калибровка. Главная современная страница.
- [Snapmaker U1](/printers/snapmaker/u1) — многоцветный принтер CoreXY на Klipper со сменщиком инструмента SnapSwap на 4 головы.
- [Anet A8](/printers/anet/a8) — сборка, улучшения безопасности, автовыравнивание стола, прошивка. Классический подробный разбор.
- [Anet ET4](/printers/anet/et4) — настройка, прошивка Klipper, калибровка.
- [Creality Ender-3 S1](/printers/creality/ender-3s1) — характеристики, моды и популярные апгрейды.
- [Wanhao Duplicator 6](/printers/wanhao/duplicator6) — компоненты, решение проблем, варианты апгрейда.
- [Klipper](/firmware/klipper/) — заметки по настройке и руководства по прошивке для отдельных принтеров.

## Зачем нужна вики?

Discord, сабреддиты и форумы живут дальше, а ответы теряются в ленте. Эта вики собирает долговечную информацию: что из себя представляет принтер, что в нём ломается, как это починить и какие моды стоят потраченного времени.

## Как помочь

Любую страницу можно отредактировать по ссылке **Edit this page on GitHub** внизу страницы или открыв pull request в [github.com/vidschofelix/3dprintwikipage](https://github.com/vidschofelix/3dprintwikipage). Для чтения аккаунт не нужен, для участия достаточно аккаунта GitHub.
