# Tronxy X5S
## Общая информация
### Характеристики

| Параметр | Значение |
|---|---|
| Модель | X5S |
| Вес машины | 7,6 кг |
| Вес брутто | 13 кг |
| Размер машины | 658 * 580 * 639 мм |
| Размер упаковки | 580 * 380 * 190 мм |
| Расходные материалы | ABS/PLA/HIPS и др. |
| Диаметр материала | 1,75 мм |
| Рама | Алюминиевый профиль |

### Технические параметры

| Параметр | Значение |
|---|---|
| Область печати | 330 * 330 * 400 мм |
| Скорость печати | 20–150 мм/с |
| Диаметр сопла | 0,4 мм |
| Толщина слоя | 0,1–0,4 мм |
| Макс. температура экструдера | 270 °C |

- Производитель [tronxy.com](http://www.tronxy.com/x-series/tronxy-x5s-3d-printer.html)
