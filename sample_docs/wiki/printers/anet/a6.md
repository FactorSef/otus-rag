# Anet A6
## Общая информация
- Производитель [anet3d.com](http://www.anet3d.com/English/3D_Printer/105.html)
- [сравнение с A8](https://pevly.com/anet-a8-vs-a6/)
### Характеристики

| Параметр | Значение |
|---|---|
| Модель | A6 |
| Вес машины | 7,6 кг |
| Вес брутто | 9,5 кг |
| Размер машины | 480 * 400 * 400 мм |
| Размер упаковки | 450 * 446 * 215 мм |
| ЖК-дисплей | LCD12864 |
| Расходные материалы | ABS/PLA/HIPS и др. |
| Диаметр материала | 1,75 мм |
| Рама | Акрил |

### Технические параметры

| Параметр | Значение |
|---|---|
| Область печати | 220 * 220 * 250 мм |
| Скорость печати | 100 мм/с |
| Диаметр сопла | 0,4 мм |
| Толщина слоя | 0,1–0,3 мм |
| Точность позиционирования XY | 0,012 мм |
| Точность позиционирования Z | 0,004 мм |
| Температура экструдера | 260 °C |
| Температура стола | 100 °C |
