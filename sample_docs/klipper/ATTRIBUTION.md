# Source and license

This folder contains an unmodified subset of the **Klipper** 3D printer firmware project:

- Repository: https://github.com/Klipper3d/klipper
- Commit: `e2b99a9159f992169c1ba53029dec020e850cc99` (2026-10-01)
- `docs/` — selected user documentation (features, installation, bed leveling and mesh, probes, pressure advance, resonance compensation, TMC drivers, FAQ, ...)
- `klippy/extras/` — selected host modules (heaters, heater bed, fans, bed screws, PID calibration, filament sensor, idle timeout)
